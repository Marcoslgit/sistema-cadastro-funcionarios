
# Sistema de Cadastro de Funcionários

Meu primeiro projeto de programação, desenvolvido com Python e SQL.

## Funcionalidades

- Criação automática da tabela de funcionários.
- Cadastro de funcionários.
- Armazenamento local utilizando SQLite.

## Tecnologias utilizadas

- Python
- SQL
- SQLite
- Git e GitHub

## Como executar

1. Instale o Python.
2. Abra o terminal na pasta do projeto.
3. Execute o comando:

   python main.py

## Objetivo

Praticar programação em Python, comandos SQL e integração com bancos de dados.
